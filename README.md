## Что это

Сатира на айти-релокантскую сцену Тбилиси, оформленная как энтерпрайз-SaaS. В тбилисской эмиграции профицит мужчин — значит, «отношениями управляют женщины, и у них есть админ-панель». Эта панель доводит шутку до абсурда: грейды претендентов, CVE-реестр прошмандовцев, бары как service mesh, Jira свиданий и граф поликюля с детектом circular dependency.

Бьём по всем поровну: по мужчинам-претендентам, по админше, по твиттерской тусовке, по релокантству как явлению и **по самой панели** — обречённому стартапу, который автор бросит через пару недель (это вшито в UI как фича — счётчик «заброшен через N дней» тикает в шапке).

## Фичи

- 📊 **Дашборд** — гейдж М/Ж намертво в красной зоне, тикер «стоимость свидания» растёт как мемкоин, drama-detector, MRR $0 / Churn 100%, хитмап районов.
- 🧑‍💻 **CRM претендентов** — грейды, lead score, заброшенные стартапы, риск релокейта в Лиссабон, RBAC-роли (`root`, `situationship`, `resurrected_ex`). Кнопки: Block («их и так мало»), Shadow-ban, Воскресить из бэкапа, Onboard as PR.
- 🛡️ **Advisories** — репутация как security advisory: `Ghosting overflow`, `Race condition: написал трём`, severity до `zero-day`, postmortem с невыполненными action items. **Строго фикшен, без реальных людей.**
- 🍸 **Инфра** — бары как ноды кластера, service map, Бассиани как auth-gate (`401: не прошёл фейс-контроль`), load balancer «чтобы не пересёкся с бывшим».
- 🎫 **Тикеты** — Jira свиданий, P0 = «отвозит в аэропорт», статусы вплоть до `Reopened (написал в 2 ночи)`.
- 🧵 **Тред-лента** — курируемый список «тбилисских тредов» + лидерборд «Главный персонаж дня».
- 🕸️ **Поликюль** — рукописный SVG-граф связей с детектом цикла («дедлок на групповом созвоне»).
- ⚙️ **Настройки** — feature flags («включить ревность» → drama-level +), канареечный релиз «я тебя люблю» на 5%, биллинг с ROI-калькулятором свидания.

«Живость» фейковая: счётчики тикают, кнопки меняют цифры на экране, ничего не сохраняется. Перезагрузка = новый рандомный мир.

## Установка

```
Открой index.html. Всё.
```

Ноль зависимостей, ноль сборки, ноль npm. Ванильный JS. Работает офлайн (кроме шрифтов с Google Fonts — без них подхватится системный фолбэк).
